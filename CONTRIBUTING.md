# Contributing

Corrections and reproduction reports are the most useful contributions. This repository holds a profile README and supporting documents, not a software product.

## Good first contributions

- **A broken link or a wrong claim** in the README or in `docs/github-portfolio/`. Open an issue naming the page and the evidence.
- **A reproduction report** for a public project: the command you ran, your environment, and the result. A failure is as useful as a pass. Report it on that project's repository.
- **A gap or overstatement** in the [evidence matrix](docs/github-portfolio/evidence-matrix.md). The rule is that every claim links to something a stranger can open.

## For changes to this repository

1. Open or reuse an issue.
2. Work on a branch; never on `main`.
3. Keep claims to what a linked artifact shows. No unverified metrics, customers, certifications or open-role claims.
4. State in the pull request which standard version you followed.
5. A maintainer approves every merge.

## What is out of scope

- Adding a licence (a decision for the owner, not a contribution).
- Marketing copy. That belongs on elliyeen.com.
- Anything that reveals private repositories, credentials or personal data.

By submitting a contribution you confirm you have the right to share it. No licence is granted by this repository beyond what each project states.
