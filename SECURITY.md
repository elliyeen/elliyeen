# Security

This repository contains documentation only: no application, secrets or customer data. Each project has its own security notes; for example, Screenwriter publishes a [threat model and known gaps](https://github.com/elliyeen/screenwriter/blob/main/docs/SECURITY.md).

## Reporting a vulnerability in any of my public projects

GitHub's private vulnerability reporting is **not currently enabled** for this repository, so please do not post exploit details in a public issue.

1. Open a public issue on the affected repository that says only *that* you have a security report, with **no technical details**.
2. Or send a LinkedIn message ([linkedin.com/in/abbasabdullah](https://www.linkedin.com/in/abbasabdullah)) saying you have a security report, and I will arrange a private channel.

I aim to acknowledge a report within a few days. These are personal and demonstration projects with no bug bounty and no guaranteed response time.

## Scope notes

- [cac-piv-pki-authentication](https://github.com/elliyeen/cac-piv-pki-authentication) and [cleared-public](https://github.com/elliyeen/cleared-public) use synthetic data and keys only. A finding there is a reference-quality issue, not a customer incident.
- [kai-dart](https://github.com/elliyeen/kai-dart) is a static demonstration on synthetic data.
- The live Screenwriter product ([write.elliyeen.com](https://write.elliyeen.com)) is in private beta and has had no third-party security audit.
